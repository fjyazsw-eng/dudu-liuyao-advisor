
## A 股现实数据强制规则

股票分析前必须读取仓库根目录 `DATA_SOURCES.md`：hithink-finance 为唯一主源，mootdx 仅补充分钟线；禁用 Tushare 和其他自动回退，失败或能力缺失明确报错。起局/起卦之后的数据仅可用于复盘；未来交易日历或公告原文若主源不支持，明确记为无法验证，不得编造。
# 嘟嘟的六爻顾问

一套面向完整六爻排盘信息的综合分析 Skill。覆盖通用断卦、用神取舍、旺衰生克、动变关系、卦辞爻辞、六神六亲、应期判断，并包含股票专题、十个交易日路径推演与复盘规则。

## 安装

下载仓库中的打包文件后导入 Codex，或直接使用仓库根目录作为 Skill 源码。

## 主要文件

- `SKILL.md`：主流程与输出约束
- `references/`：断卦框架、题型、应期、股票专题与案例复盘
- `scripts/validate_input.py`：排盘输入检查
- `agents/openai.yaml`：Skill 元数据

> 六爻内容用于传统文化研究与决策辅助；股票专题不构成投资建议。
