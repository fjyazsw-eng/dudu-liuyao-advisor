# 示例：现实背景如何改变多现用神的指向

## 盘面摘要

女问正缘何时出现，申月、丙子日、申酉空，天山遁变雷风恒。二爻勾陈官鬼午火持世发动，化子孙亥水回头克；四爻白虎官鬼午火静；应爻兄弟申金临月但旬空。

## 若没有现实背景

只能判断：官鬼两现，感情议题已进入主线，但午火失令、日冲，动爻又化回头克，近期关系不稳；遁变恒显示先退让/筛选，后续才可能走向持续。不能直接断二爻一定是正缘。

## 补充“刚分手”后

现实背景使二爻官鬼持世更合理地对应刚结束但仍占据心境的旧关系：

```text
旧官持世 → 日冲、回头克 → 关系正在退出
四爻另见官鬼 → 后续仍有男性机会
午火整体休囚 → 秋冬不是强落实期
待木旺生火、火得令 → 新关系机会增强
```

背景改变的是“哪个官鬼指旧人/新人”，没有改变午火休囚、日冲和回头克这些盘面事实。

## 合格的简洁输出

> **定性：** 近期不是马上进入稳定关系的阶段。二爻官鬼持世更像刚结束的旧情仍有余波，但它日冲又化回头克，旧线继续退；后面并非无缘，只是要先清场再起新缘。建议秋冬不急着定人，先看对方是否持续行动。
>
> **核心逻辑：** 女问感情取官鬼；旧官持世发动却受冲、回头克，难继续稳定。四爻另有官鬼，说明后续仍有对象机会。本卦遁到变卦恒，与“先退出、后稳定”一致，但恒卦不能越过午火当前弱势直接判马上成。
>
> **应期：** 秋冬先看接触和恢复；较强窗口在下一轮寅卯木旺生火至巳午火旺阶段，前者易出现或升温，后者更利确认。若届时仍只有聊天、没有持续行动，则不能仅因“官鬼出现”认作正缘。
>
> **批语：** 旧缘先退，新缘后恒。

## 错误示范

- “官鬼持世，所以正缘已经出现”：忽略现实背景和回头克。
- “恒卦，所以必定结婚”：用变卦替代主用神状态。
- “白虎官鬼必是军警、脾气暴”：单一六神过度画像。
- 从午火直接锁定某个公历日：没有先说明解除何种病处。
