# 核心判断框架

## 一、先把问题翻译成判断目标

同一句“能不能成”可能包含不同目标：出现、接触、签约、到账、录取、稳定、结婚。先明确用户真正关心哪一级结果。一个卦可以显示多个阶段，但必须有一个主结果。

把时间拆成：

- **当前：** 卦成时已经存在的状态；
- **转折：** 动变和解除病处所表示的变化；
- **结果：** 在用户所问期限内能否落实。

## 二、取用与角色

主用神代表事情本体；世爻代表求测者及其承接能力；应爻代表对方、外部环境或事情落点。原神生用，忌神克用，仇神克原而生忌。

用神多现时依次问：

1. 哪一爻最符合问题中的具体对象，而非只符合六亲名称？
2. 已知现实能否把某一爻识别为旧人、现任、目标单位、特定款项等？
3. 谁临世、应、动或变，并与结果有直接作用？
4. 谁受日月显著激活、空破、合冲，构成事件焦点？
5. 谁自身有力且作用路径完整？

“世应动优先”是候选筛选，不是不可推翻的硬排序。主用选定后，其余同类爻可代表另一对象、另一阶段或背景，但必须有第二条证据才细分。

## 三、先判断能力，再判断方向

对主用、世、主要原神和忌神各回答四问：

- 有根吗：得月日、生扶、同类或有效原神？
- 能动吗：明动、暗动，还是静而无触发？
- 被锁吗：空、破、墓、绝、合绊、伏藏、回头克？
- 能到达吗：其生克链能否真正传到用神或世爻？

然后才判断：助力是否大于阻力、用神能否成事、世爻能否承接。

## 四、建立最短作用链

不要罗列全卦所有刑冲合害。只写能改变结论的链条，例如：

```text
忌神发动但月破 → 当前难以克用
原神得月生且发动 → 能生用
用神旺而合住 → 有能力但暂不落实
待冲开合局 → 事情启动
```

优先级：

1. 日月对关键爻；
2. 本位动爻与变爻；
3. 有效动爻对用神、世爻；
4. 世用、世应的直接关系；
5. 伏神与飞神；
6. 三合、六合、六冲、刑害等结构；
7. 卦象、爻辞和六神。

## 五、形成故事线

结论应能压缩为一条因果故事：

```text
现在为何如此 → 哪股力量推动/阻碍 → 何种条件改变 → 最终偏向何处
```

如果无法说成一条故事，通常说明用神尚未选稳，或把辅助信号当成主线。

## 六、分别判断吉凶、快慢和象意

- **吉凶：** 用神是否有用、是否得助、是否受制，世爻能否承接。
- **快慢：** 动静、空破墓合、旺衰、近远期限。
- **象意：** 卦名、爻位、六神和六亲组合描述事情如何表现。

三者不能混用。例如“伏”首先是未显或受压，不自动等于最终凶；“六冲”首先是动荡、分散或加速，不自动等于所有事情失败。

## 七、输出前反证

强制找出最强反证：

- 若判断能成，最危险的阻力是什么？
- 若判断不成，是否存在得救、出空、冲墓或原神发动？
- 若给应期，该时间解除的是主病还是次要障碍？
- 若判断某爻是某个人，现实背景是否有更合理的对应？

反证不足以推翻主线时，用一句话说明“有机会但不是无条件”；能推翻时，降低结论强度或改判。
