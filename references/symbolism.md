# 卦象、爻位、卦爻辞与六神

## 主次关系

纳甲的用神、月日、动变、世应决定主判断；卦象、爻辞、爻位与六神负责回答“事情呈现成什么样”。

推荐顺序：

1. 本卦：当前局面和基本矛盾；
2. 动爻：真正发生变化的位置；
3. 变卦：变化后的趋势或归宿；
4. 动爻爻辞：与具体问题互证；
5. 六神与爻位：补人物、情绪、场景和表现。

不要把互卦、错综卦、卦身、神煞等继续叠加，除非主线已经清楚且用户明确要求高级取象。

## 本卦与变卦

- 本卦不是简单“现在”，也可能是事情的基本性质。
- 变卦不是保证实现的终局；要看动爻能否有效完成变化。
- 从本卦到变卦应翻译成一个动词过程，如退→守、聚→散、困→解、蓄→发。
- 卦名只提供宽框架。比如“恒”可指持续，也可能是状态长期不变；需看用神是得到稳定还是被困住。

## 爻辞

- 重点读取与主用、世、应或关键动爻重叠的爻辞。
- 多爻动时，不逐句堆砌全部爻辞；只取与主线一致或形成有效反证的内容。
- 原卦动爻爻辞优先。变卦整体可用于归趋，不自动把变卦同位爻辞当作第二套决定性判断。
- 爻辞语义有版本与解释分歧时，采用宽义并说明是辅助象义。

## 爻位

- 初爻：起点、基层、刚发生、近身基础。
- 二爻：内部推进、日常执行、近处关系。
- 三爻：内外转换、进退两难、阶段关口。
- 四爻：进入外部环境、接近关键层、现实接触。
- 五爻：核心位置、决策层、主要结果或正式性。
- 上爻：终端、远处、过度、退出或收尾。

爻位是情境提示，不等同固定人物清单。五爻不必然“高富贵”，上爻不必然“结束”。

## 六神

- **青龙：** 喜悦、体面、助力、宴饮、温和；遇凶用和受克时，只表示包装好或期待高。
- **朱雀：** 言语、信息、文书、传播、争辩；需结合父母看文书，结合兄弟/官鬼看口舌争执。
- **勾陈：** 牵连、拖延、固定、土地、旧事、现实负担；可表示稳定，也可表示黏滞。
- **螣蛇：** 疑虑、反复、虚惊、想象、隐曲；不可仅凭螣蛇断欺骗或灵异。
- **白虎：** 压力、强硬、伤痛、速度、冲突；在有效吉用上可表现为果断直接。
- **玄武：** 隐藏、私下、暧昧、流动、信息不透明；需与官鬼、兄弟等配合才提高欺瞒风险。

六神使用句式：

```text
六亲说明“是什么”，六神说明“怎样表现”，旺衰动静说明“表现有多强、是否发生”。
```

## 画像约束

具体人物画像至少由两类证据同向支持，例如：

- 官鬼地支五行 + 六神；
- 爻位 + 所临六亲 + 旺衰；
- 伏神/应爻状态 + 现实认识渠道；
- 卦象过程 + 动变身份变化。

不要从“酉金”直接枚举金融、司法、医生等一串职业；可概括为“偏规则、专业、精细的工作气质”，除非另有父母、官鬼、爻位和现实背景共同支持。
