# 输入与核盘

## 最低输入

至少需要：

- 一个明确的主问题；
- 起卦日期，或已经标出的月建、日辰与旬空；
- 本卦、变卦；
- 初爻至上爻的六亲与地支；
- 世爻、应爻；
- 动爻及各自变爻。

六神、伏神、卦宫、排盘软件旺衰注释属于重要增强信息。缺少六神通常不妨碍主断；缺少月日、动变或世应往往会实质影响判断。

## 推荐输入结构

```text
所问事项：
现实背景：当前状态、已知对象、已发生事件、希望判断的期限
起卦时间：
四柱/月建日辰/旬空：
本卦 → 变卦：
六爻：从初爻到上爻，列六神、伏神、本爻、世应、动静、变爻
软件注释：旺衰、日月关系、空破墓绝、回头生克、刑冲合害
```

## 核盘顺序

1. 六爻必须自下而上对应初、二、三、四、五、上；表格常按上爻到初爻展示，不要把显示顺序误当爻序。
2. 本卦应只有一个世位和一个应位；变卦世应可显示，但解读主线以本卦世应为起点。
3. 动爻数与变爻数应对应；每个变爻必须能追溯到一个本位动爻。
4. 旬空以日柱所属旬核对；月建按节气月，不按农历初一切换。
5. 伏神需同时记录飞神，飞伏关系不能只看伏神自身。
6. 软件已经标出的“月破、日冲、化回头克”等可以采用；若同一条注释互相矛盾，回到地支和五行重算。

## 错误处理

- **不影响主断：** 六神缺失、卦辞未给、某个闲爻旺衰未标。继续解读，并避免使用该维度。
- **影响细节：** 伏神飞神不清、变爻六亲缺失。可先给大方向，声明具体作用链受限。
- **影响根本：** 月日缺失、世应不明、动爻和变爻对应错误、问题不明确。先请用户补充一个最关键缺口。
- 不因软件写了“旺”“衰”便跳过核验。尤其检查：日冲究竟是暗动还是日破、旬空是否只是暂空、月破是否得到日建或动爻救应。

可用 `python scripts/validate_input.py chart.txt` 做基础完整性检查。脚本只报告缺项与矛盾候选，不替代断卦。
