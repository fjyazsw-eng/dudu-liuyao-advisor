# 股票简洁输出模板

默认需要覆盖未来约10个交易日，篇幅以完整且不重复为准；用户只要结论时再压缩。

## 固定格式

### 1. 定性与起卦前现实

第一段直接给：`偏强/强中有险/震荡/弱中有救/偏弱`、当前阶段和首要动作。随后用1—3句说明截止起卦时点的价格阶段、板块/大盘和必要公告，并标记：`高度呼应 / 基本呼应 / 部分呼应 / 呼应较弱`。现实冲突时降低置信度，不挑选性解释。

```text
定性：震荡偏弱，处于回撤后的筑底候选段。现在不是确认买点；空仓等止跌，持仓以××为失效线，反弹不追。
```

### 2. 整体结构与月建背景

固定给出：

```text
整体：……
阶段：……
月建背景：顺风 / 偏顺风 / 中性震荡 / 偏逆风 / 逆风
```

随后只保留3—5条核心逻辑：

- 财爻为何是行情主用及是否有力；
- 子孙/兄弟形成的主要多空链；
- 世爻能否承接，股价与本人盈亏是否一致；
- 最关键动变；
- 一个最强反证及裁决。

### 3. 总体节奏与10日路径

先用一行写：`当前 → 转折 → 结果`。默认再列未来约10个交易日：

```text
日期 | 关键触发 | 走势倾向 | 操作/确认
```

每格只写最重要的1—2个因素。操作使用“等、观察、持有、保护利润、条件性试仓、减仓”等，并与确认条件绑定。

### 4. 高低点、应期与条件

```text
低点窗口：××，次看××。
高点/兑现窗口：××，次看××。
只有出现……才升级为买/卖点；若……，原判断失效。
```

### 5. 空仓与持仓

- 已知用户空仓：重点输出是否参与、观察/买入窗口、不追条件和放弃条件。
- 已知用户持仓：重点输出持有、保护利润、减仓/兑现窗口和退出条件。
- 仓位未知：两套方案都给，但各用一小段，不假定成本。

### 6. 总结与批语

用一句 `核心策略：…… → …… → ……` 收束。评级默认使用“偏强、震荡偏弱、高风险”等文字，不使用A—E或单一综合分数掩盖证据差异。

8—14字，例如：`财动有机，待稳不追。`

结尾只需一句：`仅作传统术数与复盘参考，不代替交易纪律。`

## 动作词约束

- 可以用：观望、不追、等待确认、保护利润、分批处理、条件性试仓、放弃本轮。
- 谨慎用：买入、卖出；必须附条件和失效标准。
- 禁用：必涨、必跌、满仓、梭哈、保证收益、精准抄底、绝对最高/最低。

不要重复证券基本资料，不给星级、A—E评级、综合匹配度X/10或虚假精确概率；现实信息只写与阶段判断直接相关的两三项。复盘时按方向、阶段、路径、应期和可执行性分项评价。
