# 应期规则

## 总原则：先定成败，再定时间

应期不是把所有地支对应的日期都列出来。先确认事情是否具备实现条件，再找阻止它落实的“病处”。时间候选必须解除主病或激活主线。

```text
结果可成 + 当前有病 → 解除主病之时为落实窗口
结果难成 + 忌神被触发 → 该时多为受阻/定局窗口
结果未定 → 该时只称触发或观察窗口
```

## 时间尺度

- 问当天、数日：以时、日为主。
- 问数周、数月：以日与节气月为主。
- 问一年左右：以月为主，关键日为次。
- 问多年：只有卦中确有远期尺度与清晰临值链时才用年；不要因某爻属申酉便顺推到申年酉年。
- 用户未给期限时，以事情常理和动静判断最小合理尺度，并明确“先看近期窗口”。

月份以节气月计算，不把公历月或农历初一直接当寅卯月边界。

## 常用触发

- 静爻：逢值、逢冲，前提是有根；无根之冲可能冲散。
- 动爻：逢值、逢合；被合绊则待冲开。
- 旺极：逢冲、逢墓，使力量落地或转折。
- 衰绝：逢生扶、临旺令。
- 入墓：冲墓、墓被制或用神得以出墓。
- 逢合：冲开合局；合为所求时也可逢值落实，需看题意。
- 月破：填实、逢合、出月或得救神到位。
- 旬空：出旬、填实、旺空逢冲；弱空逢冲未必有用。
- 伏神：飞神被冲克空破、伏神临值或得生扶。
- 化进：本爻或进神逢值、逢合而推进。
- 化退：退神逢值或原爻逢冲时显出退意。
- 忌神阻碍：忌神受冲克、入墓、被合住且不再伤用。
- 原神不足：原神临旺、逢值或解除空破。

## 三层窗口

默认最多给三层：

1. **最早触发：** 消息、接触、变化开始；
2. **主窗口：** 最多关键条件同时满足，最可能落实；
3. **后备窗口：** 主窗口未成时，下一个同类强窗口。

每层都写触发什么，不把“遇见”“关系明确”“结婚”混成同一应期。

## 近应与远应

动而有力、用神临日月、独发、问题本身紧迫，多主快；静、伏、墓、空破叠加、隔位多阻、问长期事项，多主慢。

“未来某日地支碰到卦中某爻”只是候选，不足以独立定应。至少还需满足以下之一：

- 解除主病；
- 直接临值主用或关键原忌神；
- 完成已经存在的动变链；
- 与现实进度相符。

## 输出格式

```text
应期：最早在××出现动静；主窗口看××，因为……。若届时仍无实质推进，下一窗口为××；延迟点是……。
```

把握不足时使用“重点观察”“较强窗口”，不要伪装成确定日期。
