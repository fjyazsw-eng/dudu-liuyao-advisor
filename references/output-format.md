# 简洁输出规范

默认总长约 350—700 汉字；复杂多动卦可略长。用户明确要求详断时再展开。

## 固定结构

### 1. 定性判断

开头两三句直接回答：偏吉/偏凶、能否成、快慢和最重要建议。不要先讲用神表。

示例句式：

```text
定性：这事偏吉，但不是马上落实。机会真实，当前卡在用神旬空和世爻承接不足；先推进准备，主窗口再落地，不宜现在强求结果。
```

### 2. 核心逻辑

只列3—5条决定性证据，按重要性排序：

- 取何爻为用，为什么；
- 用神有无能力；
- 最关键动变链；
- 世爻能否承接；
- 最强阻力或转机。

### 3. 趋势与建议

用“当前 → 转折 → 结果”写一小段。建议必须与卦中病处对应，避免“保持积极”“顺其自然”等空话。

### 4. 应期提示

给最早触发、主窗口和必要时的后备窗口。说明触发条件与延迟点，不列一串日期。

### 5. 批语

8—14个汉字左右，凝练、贴题、不重新塞入整篇结论。例如：

```text
批语：先阻后通，待实则成。
```

## 表达规则

- 直说“偏吉、难成、有机会但不稳、近期不宜”等，不用大量模棱两可。
- 预测用“倾向、较可能、重点观察”，但每段最多一两个不确定词。
- 不逐爻复述软件注释；闲爻无关就不写。
- 不用星级、百分比或“准确率95%”制造虚假精确。
- 不做冗长人物画像；用户未问画像时最多一句。
- 高风险问题的现实提示放在结尾一句，不压过传统解读。

## 最终静默检查

- 是否第一段已经回答问题？
- 是否明确主用神并保持前后一致？
- 是否把旺衰和吉凶混为一谈？
- 是否解释了最关键动变，而非列全盘关系？
- 是否存在与结论相反的强证据未处理？
- 应期是否真的解除主病？
- 批语是否约十字且不夸大？
